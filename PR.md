# PR Guide / Руководство по Pull Request

## Как предлагать переводы

1. Клонируй репозиторий WokoFlipper/Omarchy-ru-locale
2. Вноси изменения в:
   - `translations/ru_RU.tsv` (меню)
   - `translations/bindings-ru.tsv` (стандартные бинды Omarchy)
   - `po/omarchy-*.po` (shell/cli)
3. Обязательно проверяй:
   - `msgfmt --check po/*.po`
   - Применяй и тестируй локально
4. Делай коммит с понятным сообщением (на русском или английском)
5. Открывай PR в этот репозиторий

## Статус текущих PR (обновляется вручную или через track.sh)

- sbelcl/omarchy-language#1 — меню (открыт)
- omacom/omarchy-site#322 — сайт (открыт, формат верный, ждём мейнтейнеров)
- omacom/omarchy#11139 — ветер и единицы (открыт)
- omacom/omarchy#11308 — отпечаток пальца (открыт)
- omacom/omarchy#8765 — рантайм i18n (бэкаем; альтернатива #10051)
- omacom/omarchy#10955 — даты через системную локаль (бэкнуто с ru_RU-подтверждением)
- omacom/omarchy#7284 — обсуждение локализации (ответ sbelcl опубликован)

## Что НЕ переводить сейчас

- Личные бинды пользователя (voice, STT, конкретные приложения и т.д.)
- Строки, которые уже переведены в системных пакетах (fprintd и т.д.)

## Бинды

В репозитории сохранены переводы только стандартных биндов Omarchy (см. translations/bindings-ru.tsv, 204 записи).
Личные переопределения не включаются. Локально переводы биндов НЕ применяются (конфликтуют с самими биндами).

## После одобрения

- Пушь в основной Omarchy когда мейнтейнеры примут
