# wifi-dns-ru 2.0 — Wi-Fi + DNS RU

## Зачем / Why

**RU:** Стоковый виджет предлагает Cloudflare (1.1.1.1) и Google (8.8.8.8) — оба заглушены в России. Этот форк меняет кнопки на рабочие. DNS4EU заменил мёртвый dns0.eu (не отвечает больше года): для России это рабочий и быстрый вариант (~1 мс, замерено), плюс EU-юрисдикция. Все варианты проверены методом испытаний в реальных условиях. Временное решение, пока мейнтейнеры не разрешат локальные пресеты (upstream issue: RU DNS presets).

## v2.0: кнопки-кольца + протоколы

Пять кнопок: DHCP фиксирован; средние три циклируют DNS по тапу (DoT по умолчанию):

- приватные: NextDNS (45.90.28.0) → DNS4EU (86.54.11.100)
- базовые: OpenDNS (208.67.222.222) → AdGuard (94.140.14.14)
- альтернаты: Mullvad (194.242.2.2) → CleanBrowsing (185.228.168.9)

Пятая кнопка — ⚠Яндекс (77.88.8.8, обычный UDP): опасен (юрисдикция РФ, СОРМ), оставлен для паритета замеров скорости — Яндекс меряет корректно.

Тогл протокола (DoT / DoH / DoQ) над кнопками: DoT нативно, DoH/DoQ через локальный dnscrypt-proxy (DoQ = DoH по QUIC).

## Чем русская версия отличается от мировой (wifi-dns)

| | RU 2.0 (этот плагин) | Мировая 2.0 (wifi-dns) |
|---|---|---|
| Язык | Русский | Английский |
| Cloudflare / Google | Убраны (заглушены в РФ) | Есть (кольцо глобалов) |
| 5-я кнопка | ⚠Яндекс (UDP, опасен — СОРМ) | Custom (свой ввод) |
| Кольца | Приватные / базовые / альтернаты (6 провайдеров) | Глобалы / приватные / альтернаты (12 провайдеров) |
| Замер скорости | Свой, результат в шапке (↓↑, округление) | Тот же механизм |
| Спидтест-провайдер | Яндекс меряет корректно в РФ | Fast.com (глобально) |

## Что изменено / Changes vs stock `omarchy.network`

1. `dnsProviders`: `[DHCP, NextDNS, DNS4EU, OpenDNS, Custom]` (было: DHCP, Cloudflare, Google, Custom).
2. Тултипы кнопок + `root.refresh()` после смены DNS (`onExited`).
3. Остальное — сток.

## Установка / Install

```bash
./install.sh
```

Перезапустить шелл: `omarchy-restart-shell`. Смена DNS идёт только через
auth-диалог polkit-агента (каждый клик).

**Про sudo: переключение ТОЛЬКО с запросом.** Каждый клик по кнопке
показывает auth-диалог через polkit-агента. Тихого (парольного) режима нет
сознательно: молчаливое переключение DNS любым локальным процессом —
дыра, закрыта 22.09. Детали — в `SECURITY.md`.

## Удаление / Remove

```bash
./remove.sh
```

Возвращает стоковый `omarchy.network` (личные файлы — в бэкап с меткой времени).

## Восстановление / Restore

`~/.config` обновлениями не затирается, но на всякий случай:

```bash
./restore.sh   # переустановить из этого репо
```
