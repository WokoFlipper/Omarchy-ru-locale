# Релизы wifi-dns-ru (по порядку)

Имя и id плагина неизменны (`wifi-dns-ru`, «Wi-Fi + DNS RU»).

## v1.0.0 — первый релиз

Пилюли: DHCP / Quad9 / DNS4EU / OpenDNS / Custom.
Стоковые Cloudflare и Google в России заблокированы/заглушены, поэтому
заменены рабочими. DNS4EU пришёл на смену мёртвому dns0.eu (не отвечал
больше года). Снапшот соответствует опубликованному состоянию (GitHub).

## v1.1.1 — второй релиз

Пилюли: DHCP / NextDNS / DNS4EU / OpenDNS / Custom.
Quad9 заменён на NextDNS (45.90.28.0, DoT — проверен живьём, оба адреса
отвечают). Переключение — только через auth-диалог polkit (парольный
грант удалён 22.09 как дыра). Подробности «почему так» — в корневом
`README.md` и `SECURITY.md`.
