# SECURITY — wifi-dns-ru

## Модель: ТОЛЬКО с запросом

Плагин в рантайме работает **без root**: QML + вызов системной утилиты
`omarchy-dns`. Смена DNS идёт **только через auth-диалог polkit-агента** —
каждый клик, без исключений. Тихого режима нет: парольное sudo-правило
удалено из пакета 22.09 как дыра (любой локальный процесс мог молча
менять DNS). Почему так: смена DNS пишет системный конфиг
NetworkManager — действие уровня root, и единственный честный способ
дать его из панели без терминала — явное подтверждение человека.

## Честные риски (что осталось и почему приемлемо)

- **Нет агента — нет переключения** (fail-closed): диалог показать некому,
  пилюля молча не срабатывает. Это безопасный отказ; живучесть агента
  проверяет хук (`polkit-agent`). Хуже было бы наоборот — тихое «получилось».
- **Значения пилюль — код** (`DHCP/NextDNS/DNS4EU/...`): опечатка = несматченный
  провайдер = отказ. Поэтому старые написания оставлены алиасами в скрипте.
- **После смены — флэп соединения**: NM перезагружает стек, виджет тянет
  свежее состояние (`refresh()`), секунду может казаться «нет подключения».
- **Обновления затирают системные файлы** (скрипт, панель): закреплённые
  копии + pacman-хук + drift-хук возвращают; правит `reapply.sh` вручную.
- Marketplace-верификация (если будет) — не аудит безопасности.
