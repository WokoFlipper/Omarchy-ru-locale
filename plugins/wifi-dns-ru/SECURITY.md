# SECURITY — wifi-dns-ru

## Модель

Плагин в рантайме работает **без root**: QML + вызов системной утилиты
`omarchy-dns`. Root нужен только смене DNS, и только одним из двух путей:

1. **По умолчанию — промпт.** Каждый клик по пилюле показывает auth-диалог
   через polkit-агента сессии. Тихого переключения нет.
2. **Опционально — парольный грант** (`omarchy-dns.sudoers` из этого пакета):
   ставится вручную в терминале, после чего переключение тихое.
   Удаляется так же вручную (`sudo rm /etc/sudoers.d/omarchy-dns`).

## Честные риски

- С грантом **любой локальный процесс может молча менять DNS**. Аргументы
  ограничены фиксированными провайдерами (свой IP подсунуть нельзя:
  скрипт чистит `PATH` и переисполняет упакованный путь), но промпта нет
  как класса. Поэтому грант — опция, а не дефолт.
- Без гранта риск сводится к обычному polkit: диалог на каждое действие.
- Marketplace-верификация (если будет) — не аудит безопасности.
