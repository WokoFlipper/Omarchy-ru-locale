# Установка русского меню Omarchy

Пошаговая инструкция на русском. Английский вариант — в README репозитория
`sbelcl/omarchy-language` (раздел про `menu-translate`).

## Что получится

Все пункты меню Omarchy — по-русски (137 строк). Иконки и действия целы,
английский остаётся в поле `description`, поэтому строку находят и по
`сеть`, и по `network`. Имена продуктов (Steam, Docker, Tailscale) специально
не переводятся.

## Шаг 0. Проверь локаль

```bash
locale -a | grep -i ru_RU
```

Должно быть `ru_RU.utf8`. Если нет — сгенерируй:

```bash
sudo sed -i 's/^#\(ru_RU.UTF-8\)/\1/' /etc/locale.gen
sudo locale-gen
```

## Шаг 1. Возьми перевод

```bash
git clone https://github.com/sbelcl/omarchy-language.git
cd omarchy-language
```

Наша таблица уже вмержена туда (`translations/ru_RU.tsv`, 137 строк).
Кто хочет править — правится правая колонка, левая (английская) не трогается:
по ней идёт поиск совпадений.

## Шаг 2. Примени

```bash
./menu-translate apply ru_RU.UTF-8
```

Ожидаемый вывод: `state=on locale=ru_RU rows=335` — столько строк в живом
меню после применения.

## Шаг 3. Проверь

Открой меню: пункты по-русски, иконки на месте, действия работают.
Поиск находит и `сеть`, и `network`.

## Откат

```bash
./menu-translate remove
```

Меню вернётся к английскому, ничего не ломается.

## Частые вопросы

**Почему не весь интерфейс по-русски?**
Меню — это данные (JSONC), их можно подменить таблицей. Остальные строки
шелла зашиты в код плагинов — для них нужен рантайм переводов (вопрос
omacom/omarchy#8765). Панели (часы, питание, звук) уже читают каталог
`locales/ru.json` через форки sbelcl.

**Почему оверрайд — целой строкой, а не одной меткой?**
`parseMenuJsonc` разворачивает каждую запись в полный объект с пустыми
дефолтами до слияния, поэтому `{"label": "…"}` тихо роняет иконку и действие.
Строка копируется целиком — так задумано, не баг таблицы.

**Строка Custom / DNS не перевелась — так надо?**
Да. `omarchy-dns` печатает слово `Custom`, а меню сравнивает с ним вывод —
перевод роняет выбор молча (см. omacom/omarchy#12344). Протокольные слова
не переводятся.

**Имена приложений (Spotify, 1Password) остались английскими?**
Личные и сторонние приложения не входят в таблицу — только стандартные
пункты Omarchy.
