# Spec: перевод руководства Omarchy на русский (manual-ru)

## Objective
Полный русский перевод руководства пользователя Omarchy (51 страница, ~195 КБ),
чтобы русскоязычный пользователь проходил установку и настройку без английского.
Успех: все 51 страницы переведены, сверены с текущей стоковой версией, лежат в репо.

## Допущения (поправь сразу, если не так)
1. Источник: `manual/` апстрима (omacom/omarchy, ветка quattro/master) на момент старта.
2. Переводим текст и заголовки; скриншоты остаются английскими (переснятие — отдельно, если захочешь).
3. Термины — как в сайте (#251) и панелях (ru.json): стол, панель, виджет, бинды — где уже устоялось.
4. Стиль: ты — последнее слово по-русски; черновик показываю, правишь, фиксируем.
5. Обновления апстрима после перевода отслеживаем вручную (дифф manual/ при свипах).

## Структура
```
translations/manual-ru/NN-название.md   → переводы (имена = стоковые номера+слаг)
translations/manual-ru/IMAGES.md        → какие скриншоты чьи (если переснимаем)
```

## Команды
- Проверка: `ls translations/manual-ru | wc -l` (= 51), `diff <(ls stock) <(ls ours)`
- Линт: без битого markdown (заголовки, код-блоки, ссылки целы)

## Стиль (пример)
EN: `Press SUPER + SPACE to open the Omarchy menu.`
RU: `Нажми SUPER + SPACE, чтобы открыть меню Omarchy.`
Клавиши и команды — как есть, латиницей. Обращение на «ты» (как в панелях).

## Тестирование (приёмка по батчам)
- Каждый батч: файлы на месте, markdown валиден, термины сверены с ru.json/site-decisions
- Финал: 51/51, дифф имён со стоком пуст, ты вычитал

## Границы
- Always: сверять термины с существующими каталогами; нумеровать как в стоке
- Ask first: переименовать/пропустить страницу; менять структуру каталога
- Never: переводить скриншоты без команды; править стоковые файлы

## Батчи (порядок)
1. 01–10 (welcome, старт, навигация, бар) — самое читаемое
2. 11–20 (скриншоты, терминал, neovim, AI, девтулы)
3. 21–30 (приложения, игры, обновления, дотфайлы, плагины)
4. 31–40 (железо, сеть, сон, шрифты, обои, промпт)
5. 41–51 (твики, темы, Mac, траблшутинг, FAQ, снапшоты, безопасность, установки)
