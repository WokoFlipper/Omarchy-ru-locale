## Корни (по фактам, не гадание)
1. Переключение требует root; путь из панели — `pkexec` (парольного sudoers-гранта не было).
   Агент в сессии есть (регистрирует сам шелл, `omarchy polkit agent registered`),

2. Хук покрывал только пилюли, не auth-путь → расширен (`dns-sudo-grant` проверка).
3. Поставлен `/etc/sudoers.d/omarchy-dns` (вручную в терминале): тихий sudo для
   одной команды. Проверка: `sudo -n -l -l /usr/bin/omarchy-dns` → `!authenticate`;
   переключение DHCP→Quad9 без терминала, резолв жив.
4. Виджет после смены DNS оставлял «нет подключения»: в `onExited` DNS-ветка не
   дёргала `root.refresh()` (band-ветка дёргает). Добавлен `root.refresh()` в
   `~/.config/omarchy/plugins/resty.network/Panel.qml` (бэкапы: `~/backups/resty.network-Panel.qml-2026-09-22*`).
5. 14:53 `omarchy-dns DHCP` через sudo (тест пилюль — переключение РАБОТАЕТ);
